# HU-05: Buscar campañas

Como usuario quiero buscar campañas para financiar una campaña de alguien.

## Alcance acordado

Búsqueda textual sencilla por nombre. No se implementa búsqueda semántica ni tolerancia a errores ortográficos. Se ignoran mayúsculas, tildes y espacios al principio o al final. El texto completo de la consulta debe estar contenido en el título.

CA 1 ajustado: desde Main, al escribir en la barra aparecen las campañas cuyo nombre coincide total o parcialmente con el texto ingresado. La coincidencia exacta aparece primero; las restantes se ordenan alfabéticamente y por ID en caso de empate.

CA 2: al pulsar una sugerencia se abre la vista de esa campaña.

La consulta vacía oculta las sugerencias. Una consulta sin coincidencias muestra “No se encontraron campañas”. Los errores de carga tienen su propio mensaje.

## Implementación y pruebas

CampaignSearch se comparte entre Main y la página de búsqueda. Reutiliza GET /api/campanias/ y filtra en el navegador, adecuado para el volumen del proyecto académico. No requiere dependencias ni migraciones nuevas.

- frontend/unit/buscarCampanias.test.js: coincidencia exacta y parcial, normalización, consulta vacía, sin coincidencias y búsqueda exclusiva en título.
- frontend/tests/busqueda.spec.js: búsqueda y navegación con API real, consulta vacía/sin resultados, error de carga simulado.

Desde frontend:

```powershell
node --test unit/buscarCampanias.test.js
npm.cmd run build
npx.cmd playwright test tests/busqueda.spec.js --project=brave --headed --workers=1 --reporter=list
```

Para Playwright deben estar funcionando Django, PostgreSQL y Vite. Las pruebas crean una cuenta y campañas de prueba en la base local de desarrollo. Puede usarse --project=edge si Brave no está configurado en el equipo.
