# HU-04: Mis campañas

Como creador de campañas quiero ver mis campañas para saber el alcance de mis proyectos.

La funcionalidad fue integrada en HU-03. Esta entrega amplía su verificación sin duplicar pantallas ni endpoints.

| Criterio | Implementación | Evidencia automatizada |
| --- | --- | --- |
| CA 1: entrar desde Main y listar las campañas propias | Enlace Ver mis campañas, ruta /campaigns/my y GET /api/campanias/mis/ filtrado por creador | test_mis_campanias_solo_propias y prueba HU04 de campanias.spec.js: dos propias, exclusión de una ajena |
| CA 2: abrir una campaña desde el listado | Cada tarjeta enlaza a /campaigns/:id | Prueba HU04: abre ambas tarjetas y comprueba URL, título y descripción correspondientes |

El listado incluye todas las campañas del creador, sin filtrar por fecha. Tener una campaña activa es una precondición del criterio, no un requisito de ocultar las vencidas.

## Verificación en Windows

Desde la raíz, con PostgreSQL disponible y DB_NAME configurado:

```powershell
.\.venv\Scripts\python.exe -m pytest api/test_campanias.py --ds=config.settings -v
```

Con Django y Vite iniciados, desde frontend:

```powershell
npx.cmd playwright test tests/campanias.spec.js --project=edge --workers=1 --reporter=list
```

La ejecución en PostgreSQL y Edge debe confirmarse en el equipo local. La detección de pruebas con --list no sustituye su ejecución.
